# Portfolio · José Luis Orta Durán

Personal portfolio (Backend Engineering Lead). Static site, no build dependencies.

```
src/content.html   page source (edit this)
build.sh           generates docs/index.html from src/content.html
docs/              published output served by GitHub Pages
```

- Edit `src/content.html`, then run `./build.sh`.
- GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `/docs`.
- English by default with a Spanish toggle; light/dark follows the system theme.
